# Validation Timeline & Practical Process

## Overview

Scale validation is a **multi-phase, iterative process** that typically takes 1-3 years for comprehensive validation. This guide provides realistic timelines, sample size requirements, and practical advice for each phase.

---

## Validation Levels & Time Requirements

### Quick Reference

| Validation Level | Timeline | Studies | Minimum for |
|-----------------|----------|---------|-------------|
| **Minimal** (Exploratory) | 3-6 months | 1 study | Pilot research, dissertations |
| **Standard** (Publication) | 9-18 months | 2-3 studies | Journal articles, applied research |
| **Comprehensive** (Scale Development) | 1-3 years | 4-6 studies | Scale development papers |
| **Gold Standard** (Major Scales) | 3-10+ years | Many studies | Widely-used instruments |

**Choose based on:**
- Research goals
- Publication requirements
- Available resources
- Novelty of construct

## Phase 1: Item Development (3-6 months)

### Goals
- Define construct clearly
- Generate comprehensive item pool
- Establish content validity

### Steps

#### Month 1: Construct Definition & Literature Review
**Activities:**
- [ ] Write clear construct definition
- [ ] Conduct systematic literature review
- [ ] Identify existing measures (gaps & strengths)
- [ ] Specify theoretical framework
- [ ] Define dimensions/facets

**Deliverables:**
- Construct definition document
- Literature synthesis
- Theoretical framework diagram

#### Month 2: Qualitative Research (Optional but Recommended)
**Activities:**
- [ ] Conduct interviews (n = 10-20)
- [ ] Run focus groups (2-3 groups)
- [ ] Analyze qualitative data
- [ ] Extract potential item content

**Deliverables:**
- Qualitative themes
- List of potential items from participants

#### Month 3: Item Writing
**Activities:**
- [ ] Generate initial item pool (2-3x final length)
- [ ] Write items using best practices
- [ ] Create response format
- [ ] Balance item types/dimensions

**Deliverables:**
- Initial item pool (40-60 items for 15-20 item scale)

#### Month 4-5: Expert Review
**Activities:**
- [ ] Recruit experts (5-10 people)
- [ ] Create expert review survey
- [ ] Experts rate items (relevance, clarity)
- [ ] Calculate CVR/CVI
- [ ] Collect qualitative feedback

**Deliverables:**
- Expert ratings data
- Content validity indices
- Revised item pool

#### Month 6: Cognitive Interviews
**Activities:**
- [ ] Recruit participants from target population (n = 5-10)
- [ ] Conduct think-aloud interviews
- [ ] Identify confusing items
- [ ] Make final revisions

**Deliverables:**
- Final item pool ready for pilot testing
- Item revision documentation

### Resources Needed
- **Personnel:** Research team, expert panel
- **Participants:** Interview/focus group participants (10-30 people)
- **Budget:** Participant incentives ($200-500), transcription

## Phase 2: Scale Refinement (3-6 months)

### Goals
- Reduce items to final scale
- Establish factorial structure
- Assess initial reliability
- Gather preliminary validity evidence

### Study 1: Exploratory Factor Analysis (EFA)

#### Sample Requirements
**Minimum:** 200 participants
**Preferred:** 300-500 participants

**Ratio rules:**
- 5 participants per item (minimum)
- 10 participants per item (preferred)

**Example:** 40-item pool → 200-400 participants

#### Timeline: Months 1-3

**Month 1: Data Collection**
- [ ] Recruit participants
- [ ] Administer scale
- [ ] Include convergent validity measures (2-3 scales)
- [ ] Collect demographic data

**Month 2: Data Cleaning & EFA**
- [ ] Screen data (missing values, outliers)
- [ ] Check assumptions (KMO, Bartlett's)
- [ ] Run EFA (multiple extraction/rotation methods)
- [ ] Determine number of factors
- [ ] Examine factor loadings

**Month 3: Item Reduction & Analysis**
- [ ] Delete poor items (loading < 0.40, cross-loading)
- [ ] Re-run EFA with reduced item set
- [ ] Calculate reliability (Cronbach's α)
- [ ] Test convergent validity (correlations)
- [ ] Write up results

#### Deliverables
- Reduced item pool (typically 15-25 items)
- Factor structure hypothesis
- Reliability estimates
- Preliminary validity evidence

### Resources Needed
- **Participants:** 200-500 people
- **Budget:** Incentives ($500-2000), data collection platform
- **Software:** SPSS, R, or similar for EFA
- **Time:** ~15 hours data collection + 20 hours analysis

---

## Phase 3: Confirmation (3-6 months)

### Goals
- Confirm factor structure in new sample
- Establish construct validity
- Test reliability in new context
- Gather additional validity evidence

### Study 2: Confirmatory Factor Analysis (CFA)

#### Sample Requirements
**Minimum:** 200 participants (NEW sample, not Study 1)
**Preferred:** 300-500 participants

**Critical:** Must be independent from EFA sample

#### Timeline: Months 1-3

**Month 1: Data Collection**
- [ ] Recruit new sample
- [ ] Administer final scale
- [ ] Include convergent validity measures (3-4 scales)
- [ ] Include discriminant validity measures (2-3 scales)
- [ ] Collect criterion variables (if possible)

**Month 2: CFA Analysis**
- [ ] Specify CFA model based on EFA results
- [ ] Test model fit (CFI, TLI, RMSEA, SRMR)
- [ ] Examine modification indices
- [ ] Make theoretically justified modifications
- [ ] Compare alternative models

**Month 3: Validity Testing**
- [ ] Calculate composite reliability
- [ ] Test convergent validity (correlations, AVE)
- [ ] Test discriminant validity (Fornell-Larcker, HTMT)
- [ ] Test concurrent/predictive validity
- [ ] Write up results

#### Deliverables
- Confirmed factor structure
- Final scale version
- Comprehensive validity evidence
- Reliability across samples

### Study 3: Test-Retest Reliability (Optional, can run in parallel)

#### Sample Requirements
**Minimum:** 50 participants
**Preferred:** 100+ participants

#### Timeline: 1-2 months

**Week 1: Time 1 Data Collection**
- [ ] Recruit participants
- [ ] Administer scale
- [ ] Collect contact information

**Weeks 2-3: Wait Period**
- [ ] 2-4 week interval (construct-dependent)

**Week 4: Time 2 Data Collection**
- [ ] Re-contact participants
- [ ] Administer scale again
- [ ] Track retention rate

**Week 5: Analysis**
- [ ] Calculate test-retest correlation
- [ ] Examine mean differences
- [ ] Calculate ICC
- [ ] Assess stability

### Resources Needed
- **Participants:** 200-500 (Study 2) + 50-100 (Study 3)
- **Budget:** $1000-3000
- **Software:** Mplus, AMOS, lavaan (R) for CFA
- **Time:** ~20 hours data collection + 30 hours analysis

---

## Phase 4: Nomological Network Testing (6-12 months)

### Goals
- Test theoretical relationships
- Establish predictive validity
- Cross-validate across contexts
- Demonstrate practical utility

### Study 4: Predictive Validity (Longitudinal)

#### Sample Requirements
**Minimum:** 150 at Time 1 (accounting for 20-30% attrition)
**Preferred:** 250+ at Time 1

#### Timeline: 6-12 months

**Month 1: Time 1 Data Collection**
- [ ] Recruit participants
- [ ] Administer scale
- [ ] Measure potential antecedents
- [ ] Measure baseline criterion variables
- [ ] Collect contact information

**Months 2-5 or 2-11: Follow-up Period**
- Time lag depends on criterion
  - Job performance: 6 months
  - Turnover: 12 months
  - Academic outcomes: 1 semester

**Month 6 or 12: Time 2 Data Collection**
- [ ] Re-contact participants
- [ ] Measure criterion variables
- [ ] Track attrition

**Final Month: Analysis**
- [ ] Analyze attrition bias
- [ ] Test predictive relationships
- [ ] Control for baseline
- [ ] Calculate effect sizes

#### Deliverables
- Predictive validity evidence
- Nomological network support
- Practical utility demonstration

### Study 5: Cross-Validation (Optional)

#### Sample Requirements
**Varies:** Different populations/contexts

**Examples:**
- Different industries
- Different cultures/languages
- Different age groups
- Clinical vs. non-clinical samples

#### Timeline: 3-6 months per context

**Activities:**
- [ ] Adapt scale if needed (translation, context)
- [ ] Collect data (n = 200+ per group)
- [ ] Test measurement invariance
- [ ] Compare factor structure
- [ ] Assess reliability across groups

#### Deliverables
- Evidence of generalizability
- Measurement invariance results
- Boundary conditions identified

### Resources Needed
- **Participants:** 150-250+ (longitudinal) + additional for cross-validation
- **Budget:** $1500-5000 (depends on incentives, follow-up costs)
- **Time:** Substantial (6-12 months for longitudinal)

## Complete Validation Timeline Summary

### Minimal Validation (3-6 months)
```
Month 1-3:  Item development + expert review
Month 4-6:  Pilot study (n=200)
            - EFA
            - Internal consistency
            - Basic convergent validity

Total: 6 months, 1 study, ~$1000-2000
```

### Standard Validation (9-18 months)
```
Month 1-6:  Phase 1 - Item development
Month 7-9:  Phase 2 - Study 1 (EFA, n=300)
Month 10-12: Phase 3 - Study 2 (CFA, n=300)
Month 13-15: Study 3 - Test-retest (n=100)
Month 16-18: Analysis, writing, revision

Total: 18 months, 3 studies, ~$3000-6000
```

### Comprehensive Validation (1-3 years)
```
Year 1:     Phases 1-3 (as above)
Year 2:     Phase 4 - Longitudinal study
            Cross-validation studies
Year 3:     Additional validity evidence
            Publication preparation

Total: 2-3 years, 5-6+ studies, ~$10,000+
```

## Sample Size Cheat Sheet

| Analysis Type | Minimum n | Preferred n | Notes |
|---------------|-----------|-------------|-------|
| **Expert Review** | 5 experts | 8-10 experts | More = better CVR power |
| **Cognitive Interviews** | 5 participants | 8-10 | Diminishing returns after 10 |
| **EFA** | 200 | 300-500 | 5-10 per item |
| **CFA** | 200 | 300-500 | Independent from EFA |
| **Test-Retest** | 50 | 100+ | Higher for ICC precision |
| **Predictive Validity** | 150 (Time 1) | 250+ | Account for attrition |
| **Known Groups** | 30 per group | 50+ per group | Depends on effect size |

**General rule:** More is better, but diminishing returns after ~500 for most analyses.

### Minimal Validation Budget (~$1000-2000)
- Participant incentives: $800-1500
- Survey platform: $0-200/year
- Software: $0 (use R/free tools)
- Total: ~$1000-2000

### Standard Validation Budget (~$3000-6000)
- Participant incentives: $2000-4000
- Survey platform: $200-500/year
- Software: $500-1000 (SPSS, Mplus licenses)
- Expert incentives: $200-500
- Total: ~$3000-6000

### Comprehensive Validation Budget (~$10,000-30,000)
- All above costs × multiple studies
- Longitudinal tracking costs
- Translation/adaptation: $1000-3000
- Conference presentations: $2000-4000
- Open-access publication fees: $2000-4000
- Total: ~$10,000-30,000+

## Common Pitfalls & How to Avoid Them

### Pitfall 1: Rushing the Process
**Problem:** Skipping phases leads to weak evidence
**Solution:** Follow systematic timeline; don't cut corners

### Pitfall 2: Same Sample for EFA and CFA
**Problem:** Capitalization on chance; inflated fit indices
**Solution:** Always use independent samples

### Pitfall 3: Underestimating Sample Size
**Problem:** Unstable factor solutions; low power
**Solution:** Use sample size guidelines; collect 10% extra for exclusions

### Pitfall 4: Poor Retention in Longitudinal Studies
**Problem:** Attrition bias; inadequate power
**Solution:** Collect thorough contact info; offer incentives; maintain engagement

### Pitfall 5: No Time for Revisions
**Problem:** Stuck with problematic scale
**Solution:** Build in 3-6 month buffer for unexpected issues

## Decision Tree: Which Validation Level?

### Choose MINIMAL if:
- ✓ Exploratory research
- ✓ Dissertation/thesis with limited time
- ✓ Using established scale in new context (just need reliability check)
- ✓ Very limited resources

### Choose STANDARD if:
- ✓ Publishing in peer-reviewed journal
- ✓ Applied research with practical implications
- ✓ Adapting existing scale significantly
- ✓ Moderate resources available

### Choose COMPREHENSIVE if:
- ✓ Developing new scale for field
- ✓ Publishing in top-tier methodological journal
- ✓ Scale will be widely used
- ✓ Substantial resources available

## Practical Tips

### Tip 1: Run Studies in Parallel
- Conduct test-retest while analyzing EFA
- Start CFA recruitment while finishing EFA analysis
- **Saves time:** Can reduce timeline by 20-30%

### Tip 2: Use Online Platforms
- MTurk, Prolific, CloudResearch for quick recruitment
- Qualtrics, SurveyMonkey for data collection
- **Faster & cheaper** than in-person

### Tip 3: Preregister Hypotheses
- Specify factor structure before CFA
- Register predicted relationships
- **Strengthens evidence**, prevents p-hacking

### Tip 4: Collect Extra Data
- Include measures you might need later
- Collect demographic variables
- **Cheaper** than running new study

### Tip 5: Build a Validation Plan Document
- Outline all phases
- Specify analyses a priori
- Track progress
- **Keeps project organized**
